## 先搞清楚 CN2 GIA 到底贵在哪

CN2 是中国电信的国际承载网，里面有两条差别很大的线路：CN2 GT（Global Transit）和 CN2 GIA（Global Internet Access）。GT 便宜、容易被塞满；GIA 是优先级更高的那档，全程走独立出口，回程不经过 202.97 这类拥堵节点。判断方法也不玄学——traceroute 里出现 `59.43.x.x` 段，基本就是 GIA；满屏 `202.97.x.x`，那就是普通 163 网络。

搬到日本机房的语境里，这件事的意义在于距离。从中国大陆访问东京，走优化线路正常在 50–90ms 这个区间（多个渠道整理的数据基本一致）；同样走 CN2 GIA 的洛杉矶机房，通常也要 150–180ms。差出来的这一百毫秒，在 SSH 敲命令、后台点菜单、下游戏补丁的时候是能感觉到的。

代价就是贵。日本 CN2 GIA 这个品类，月付 20 美元基本是地板价，往下找多半要牺牲点什么。

## 挑日本 CN2 GIA VPS，四个最容易踩的坑

1. **去程优化当成双程优化。** 有些方案只做回程 GIA，去程走普通国际出口。你 ping 得好看，上传照样卡。买之前把去程路由一起问清楚。
2. **只写“CN2”，不写“GIA”。** 这两个词在商家文案里经常被混用，实际是两套带宽池，价格差一倍不止。
3. **超量策略不一致。** 同样是“流量用超”，有的限速继续跑，有的直接暂停实例。做生产业务前必须确认属于哪一种。
4. **库存。** 日本走大陆优化线路的机器普遍是限量供应，缺货是常态，不是营销话术。看到有货再纠结，通常就没了。

## 买之前常被问到的几个问题

**延迟真有那么低吗？** 走优化线路时，中国大陆到东京的 ping 值一般落在 50–90ms，具体看你所在的城市和运营商。移动和联通的表现跟电信不完全一样。结论别信任何人转述，用自己的网络 ping 官方测试 IP。

**能解锁流媒体吗？** 日本机房的 IP 在解锁日区服务这件事上，通常比美区、欧洲机房省事，但主流平台的风控规则一直在改，任何“保证解锁”的说法都不可靠。把它当附加效果，别当购买理由。

**流量跑超了会怎样？** Pro 系列直接暂停实例，不会继续计费；T1 系列限速继续跑，比如 T1.WEE 超量后降到 50Mbps 不限量。做长期在线的服务，这个差别比价格更重要。

**能中途升级配置吗？** 套餐升级属于账号后台操作，规则可能随产品线调整，下单前直接问客服最稳。

**需要备案吗？** 不需要。服务器和 IP 都在日本，不存在国内备案流程。
